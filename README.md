# Искусственные нейронные сети (ИНС)

Репозиторий содержит теоретические материалы (лекции) и практические реализации (лабораторные работы) по дисциплине «Искусственные нейронные сети». 
Курс охватывает полный путь от базовых математических моделей нейрона до современных архитектур глубокого обучения (CNN, RNN, Autoencoders) и задач обработки естественного языка (NLP).

## Темы курса (Теория)

1. **Основы нейронных сетей:** История, биологическая и математическая модели нейрона (МакКаллока-Питтса), функции активации (Sigmoid, ReLU, Tanh, Softmax).
2. **Персептрон и обучение:** Однослойный и многослойный персептрон, теорема сходимости, дельта-правило, алгоритм обратного распространения ошибки (Backpropagation).
3. **Оптимизация и Keras:** Градиентный спуск, гиперпараметры, фреймворк Keras/TensorFlow, методы борьбы с переобучением (Dropout, BatchNormalization).
4. **Сверточные нейронные сети (CNN):** Архитектура Conv2D, слои подвыборки (Pooling), AlexNet, визуализация карт признаков.
5. **Автокодировщики (Autoencoders):** AE, VAE, CVAE, Denoising Autoencoders. Применение для снижения размерности, поиска выбросов и шумоподавления.
6. **Рекуррентные нейронные сети (RNN):** Архитектуры Элмана и Джордана, BPTT, LSTM, GRU.
7. **Обработка естественного языка (NLP):** Токенизация, Bag of Words, Word Embeddings (Word2Vec, GloVe, FastText), классификация текстов.

---

## Практика (Лабораторные работы)

Все лабораторные работы выполнены в формате Jupyter Notebooks (`.ipynb`) с использованием `TensorFlow / Keras`.

| № | Название работы | Ключевые навыки и задачи |
|---|-----------------|--------------------------|
| **1** | **Модель нейрона** | Реализация нейрона МакКаллока-Питтса, линейного и сигмоидного нейронов. Обучение по дельта-правилу. Визуализация линейной разделимости. |
| **2** | **Основы Keras и MLP** | Создание последовательной модели (`Sequential`), полносвязные слои (`Dense`). Классификация рукописных цифр (MNIST). Визуализация процесса обучения. |
| **3** | **Валидация и регуляризация** | Анализ переобучения. Применение слоев `Dropout` и `BatchNormalization`. Подбор гиперпараметров (на примере датасета Sonar). |
| **4** | **Сверточные нейронные сети (CNN)** | Слои `Conv2D`, `MaxPooling2D`, `Flatten`. Обучение CNN на MNIST. Распознавание собственных рукописных цифр. |
| **5** | **Аугментация и KerasTuner** | Увеличение датасета с помощью `ImageDataGenerator`. Автоматическая оптимизация гиперпараметров через `KerasTuner` (RandomSearch, Bayesian). Датасет CIFAR-10. |
| **9.1** | **NLP: Bag of Words vs Embedding** | Токенизация текстов. Классификация текстов по авторам. Сравнение подходов `Bag of Words` и `Embedding` + `Dense`. |
| **9.2** | **NLP: RNN и CNN для текстов** | Применение `SimpleRNN`, `LSTM`, `GRU` и `Conv1D` для классификации текстов и распознавания болезней по симптомам. |

##  Как запустить код

1. Клонируйте репозиторий:
```bash
https://github.com/Ssonamy/ANN.git
cd ANN
```

2. Установите необходимые библиотеки:
```bash
pip install tensorflow numpy pandas scikit-learn matplotlib seaborn keras-tuner gdown
```

3. Откройте файлы .ipynb в Jupyter Notebook, JupyterLab или Google Colab.
